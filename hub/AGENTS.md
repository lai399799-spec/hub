## 1. 專案目的與定位
本專案為「店家地圖庫」，旨在記錄並分類精選的特色咖啡廳、美食與私房景點。透過結構化的網頁形式呈現在 GitHub Pages 上，讓使用者能快速依照地區與風格探索店家。

## 2. 網頁整體視覺與風格規範
- **視覺風格**：採日系質感暖色調。
- **元件設計**：
  - 卡片式版面，邊框採用大圓角。
  - 店家特色標籤（例如：`#有插座`、`#不限時`、`#靜謐老宅`、`#貓咪互動`），標籤以淡色背景膠囊狀顯示。
- **閱讀體驗**：頁面頂部設有固定導覽列（包含返回總首頁連結），店家詳細頁面底部提供周邊或同風格店家推薦卡片。

## 3. 專案目錄結構
本專案目錄結構規範如下：
├── index.html        # 網站總首頁（展示地區分類、風格標籤與所有店家總覽卡片）
├── AGENTS.md         # AI 規範與專案執行指引
├── pages/            # 存放單一家店家或景點的詳細介紹頁面
│   ├── daan-roaster-coffee.html
│   └── zhongshan-vintage-cafe.html
└── assets/           # 存放通用 CSS 樣式與店家圖片
    ├── style.css
    └── images/

## 4. 檔案命名與格式規則
- 所有店家網頁檔案統一使用小寫英文，並需包含地區或風格前綴，例如 `pages/taipei-daan-cafe-01.html`。
- 每篇店家詳細頁面必須包含以下區塊：
  1. 頂部導覽列（返回總選單）
  2. 店家標題與封面大圖（放置於 `assets/images/`）
  3. 基本資訊卡片（地址、營業時間、有無插座/WiFi、消費門檻）
  4. 精選推薦（必點飲品/餐點與個人評測短評）
  5. 頁尾版權宣告

## 5. AI 修改與新增內容規則 (SOP)
當使用者發出「新增店家」或「修改內容」指令時，AI 必須嚴格依序執行以下步驟：
1. **生成店家頁面**：在 `pages/` 資料夾下建立新的 HTML 檔案，套用統一的暖色調卡片風格與 CSS 樣式。
2. **自動更新總首頁連結**：讀取根目錄的 `index.html`，在總覽清單頂部新增該店家的簡介卡片、標籤與頁面跳轉連結。
3. **相對路徑驗證**：確保首頁與內頁之間的相對連結（如 `../index.html` 及 CSS 引用）設定正確無誤。
